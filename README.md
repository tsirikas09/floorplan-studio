# Floorplan Studio

Διαδραστική κάτοψη σπιτιού για το Home Assistant. Ένα integration και μία κάρτα που ζωγραφίζουν τον όροφό σου από έναν **περιγραφέα** (όροφοι, δωμάτια, συσκευές, θέσεις), χωρίς ογκώδη YAML.

*Interactive floor plan for Home Assistant. One integration + one card that draw your floors from a stored house descriptor.*

> **Κατάσταση: v0.1.0, πρώιμη έκδοση.** Δοκιμάστηκε μόνο με προσομοίωση. Αν κάτι δεν δουλέψει, άνοιξε ένα issue με το μήνυμα του browser console.

## Τι κάνει
- Ζωγραφίζει την κάτοψη (τοίχοι, έπιπλα, δωμάτια) και τοποθετεί τις συσκευές στις θέσεις τους.
- Εικονίδια ON/OFF με tooltip. Tap = εναλλαγή, κράτημα = ρυθμίσεις.
- **Πρίζες:** κεραυνάκι και watt όταν υπάρχει κατανάλωση πάνω από 2 W, και επιβεβαίωση πριν σβήσεις πρίζα που καταναλώνει.
- Λάμψη δωματίου όταν είναι αναμμένο φως. Animation στο πλυντήριο όταν πλένει.
- Πάτημα σε δωμάτιο ανοίγει το popup του (hash, π.χ. `#g_bedroom`), συμβατό με Bubble Card.
- Αυτόματη προσαρμογή σε κινητό (κάθετη κάτοψη) και αυτόματη αποφυγή επικαλύψεων εικονιδίων.
- **Επεξεργασία θέσεων μέσα στο dashboard:** κουμπί «Επεξεργασία θέσεων» (μόνο για admin), σύρσιμο ή βέλη, «Αποθήκευση».

## Εγκατάσταση
**Home Assistant 2026.11 και νεότερο (Marketplace)**
1. Ρυθμίσεις → Marketplace → *Add from link* → `tsirikas09/floorplan-studio` → Add.
2. Εγκατάσταση, μετά επανεκκίνηση του Home Assistant.
3. Ρυθμίσεις → Συσκευές και υπηρεσίες → Προσθήκη integration → **Floorplan Studio**.

**Παλαιότερες εκδόσεις:** HACS → Custom repositories → `https://github.com/tsirikas09/floorplan-studio` (Integration).

**Χειροκίνητα:** αντίγραψε τον φάκελο `custom_components/floorplan_studio` στο `/config/custom_components/` και κάνε επανεκκίνηση.

## Χρήση
Σε ένα dashboard πρόσθεσε την κάρτα:

```yaml
type: custom:floorplan-studio-card
floor: g            # id ορόφου από τον περιγραφέα (g = ισόγειο, u = πρώτος όροφος στο παράδειγμα)
orientation: auto   # auto | landscape | portrait
```

Στον κατάλογο `examples/` υπάρχουν πλήρη dashboards (κάρτα και popups). Η πρώτη εγκατάσταση φορτώνει ένα **παράδειγμα** (δύο όροφοι), το οποίο προσαρμόζεις στο δικό σου σπίτι. Δες `docs/descriptor.md` για τη μορφή.

## Σημειώσεις
- Τα popups δεν είναι μέρος της κάρτας ακόμα: χρησιμοποιούν Bubble Card (≥ 3.2) και Mushroom όπως στα παραδείγματα.
- Τα entities `todo_*` (κλιματιστικά, τηλεοράσεις, κάμερες) είναι placeholders. Αντικατέστησέ τα στον περιγραφέα.
